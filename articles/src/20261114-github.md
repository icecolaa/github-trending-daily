## 项目简介

### 01 · GoogleChrome/modern-web-guidance-src｜+1,925
Google 的 Modern Web Guidance 源仓库——一套嵌进编码 Agent 的 Web 平台技能，把现代 Web 能力、最佳实践和浏览器兼容数据直接喂给 Agent，让它别再写老掉牙的写法。由 Chrome、Edge、Firefox 与 MDN 团队共同维护，本仓库存放编写、校准与评测这些技能的代码和文档，成品在 `GoogleChrome/modern-web-guidance`。2026 年 1 月建仓，总 star 4,901。连续第三天在榜（11-12 第 8 +159 → 11-13 第 4 +739 → 今日榜首 +1,925），增量连续两天翻倍以上，接替 astryx 登顶。Apache-2.0 许可。

### 02 · we-promise/sure｜+925

### 03 · openai/codex-security｜+751
