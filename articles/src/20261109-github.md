## 新榜项目详情

### 01 · sherlock-project/sherlock｜+2,373

- **功能简介**：经典 OSINT 工具——输入一个用户名，跨 400+ 社交网络搜索该账号是否存在，一次性输出所有命中结果。
- **技术亮点**：Python 实现，以「站点清单 + 请求模板」的插件式结构覆盖站点，社区持续维护各平台的支持状态；结果可输出 JSON / CSV，方便接进调查流水线。2018 年建仓，累计 103,556 星（今日突破 10 万）、12,131 fork，是安全圈人手一个的入门工具。官方推荐 `pipx` / `uv` / Docker 安装，README 明确警告部分第三方系统包已损坏。
- **适用场景**：用户名溯源与账号关联分析、安全调查与社工测试的信息收集阶段、CTF 与红队侦察。
- **许可证**：MIT。

### 02 · milind-soni/OpenMausBot｜+1,439

- **功能简介**：开源的 Grok Bot 替代品：把一队 AI Agent 装进一个聊天软件——每个侧边栏里的「联系人」都是一个真实运行的 bot（Claude 或 Codex），各有自己的人设、模型、虚拟机和已连接的应用。
- **技术亮点**：TypeScript strict + React 19 + Electron 三端（macOS / Windows / Ubuntu），本地优先、自带模型的 bring-your-own-agent 架构；每个 bot 配一台「cloud computer」虚拟机，可以像看联系人一样看它们干活、审批关键操作。自称是 Meta Muse、OpenAI dots、Cue by Manus 的开源替代。2026 年 8 月建仓，三个月冲到 18,267 星、2,534 fork。
- **适用场景**：想要本地多 Agent 协作桌面的重度用户、不想把 API Key 托管给闭源产品的隐私敏感者、研究 Agent 编排交互形态的团队。
- **许可证**：Apache-2.0。

### 03 · meta/astryx｜+875

- **功能简介**：Meta 开源的下一代设计系统：150+ 无障碍组件，既给人用，也给「与人并肩工作的 Agent」用。
- **技术亮点**：README 自述这套系统在 Meta 内部长了八年，是公司内使用最广、体量最大的设计系统，支撑 13,000+ 个应用；开源版基于 React 19+ 与 StyleX 构建，主打 token 级可定制（brand-level customization），配齐 Storybook、Sandbox 与官方文档。目前 Beta 阶段。2026 年 1 月建仓，累计 16,820 星、1,322 fork。
- **适用场景**：想要「Meta 级」组件基建的中大型前端团队、需要设计 token 全量定制的品牌型产品、研究 design system + AI Agent 协作范式的团队。
- **许可证**：MIT。

### 04 · anthropics/skills｜+792

- **功能简介**：Anthropic 官方的 Agent Skills 仓库：一组「文件夹形式的技能包」，Claude 动态加载后可在专门任务上获得可复现的能力提升。
- **技术亮点**：每个 skill 自带 `SKILL.md`（指令 + 元数据）与脚本资源，自包含、即插即用；示例覆盖创作（艺术、音乐、设计）、技术（Web 应用测试、MCP 服务器生成）与企业流程（品牌、沟通）等方向，是学写 skill 的官方范本库。README 注明 Agent Skills 标准见 agentskills.io，仓库内多数 skill 为 Apache-2.0。2025 年 9 月建仓，累计 189,662 星、22,349 fork——是本期总 star 最高的仓库。
- **适用场景**：给 Claude / 兼容 Agent 配技能、学习 SKILL.md 编写范式、把团队流程沉淀成可复用技能包。
- **许可证**：待核实（API 未识别出仓库级统一许可证；README 称仓库内多数 skill 为 Apache-2.0）。

### 05 · ranxianglei/billion-context｜+460

- **功能简介**：上下文压缩插件：号称「100K 上下文窗口就够了」——用压缩换长会话，让单次会话可以连续跑一个月、吞吐数十亿 token，同时省下约 5 倍 token 消耗。
- **技术亮点**：npm 全局安装即用（`npm install -g billion-context`），明确适配 Claude Code、Codex、OpenCode、pi 等主流 CLI Agent；主打高压缩质量下的小窗口长跑，中英双语文档齐全。作者是独立开发者，2026 年 8 月建仓，累计 5,161 星、406 fork，README 篇幅近 8 万字符，文档密度在同类项目里罕见。
- **适用场景**：长周期单会话 Coding Agent 的省钱与续命、上下文窗口受限的模型用户、想做会话压缩方案的技术选型。
- **许可证**：待核实（API 识别为 NOASSERTION，README 链接指向仓库 LICENSE 文件，以仓库为准）。

### 06 · dsx-ai-factory/nvke｜+345

- **功能简介**：NVIDIA Kubernetes Engine（NVKE）——在自有裸机 GPU 集群上跑一套「托管式 Kubernetes 服务」的管理面：平台团队装 NVKE，为客户开出一个个体积更小的独立工作负载集群。
- **技术亮点**：Go 编写（go.work 多模块），每个 workload cluster 独享自己的控制面、etcd 与节点池；提供无 GPU 硬件也能玩的本地 quickstart（模拟机器上起开发管理面），Linux amd64/arm64、6 CPU / 12 GiB 内存即可起步。官方标注 Preview 状态、不建议生产使用。2026 年 8 月建仓，累计 855 星——今日 +345 相当于一天涨了近半个自己。
- **适用场景**：GPU 集群平台团队对外输出 K8s 服务、私有化 AI 基础设施建设、研究 GPU 调度与管理面架构。
- **许可证**：Apache-2.0。

### 07 · google-deepmind/mujoco｜+41

- **功能简介**：DeepMind 的通用多关节动力学物理仿真器（Multi-Joint dynamics with Contact），机器人仿真的事实标准之一。
- **技术亮点**：C++ 核心，接触动力学求解器精度与速度兼顾，原生支持 MJX（JAX 后端）做 GPU 并行仿真；被 RL 训练、机械臂操作、人形机器人研究的标准环境套件广泛依赖。2021 年 8 月开源进 DeepMind，累计 16,424 星、1,953 fork。
- **适用场景**：机器人与强化学习研究、sim-to-real 流程、物理引擎教学。
- **许可证**：Apache-2.0。

### 08 · anthropics/claude-quickstarts｜+32

- **功能简介**：Anthropic 官方的 Claude API 快速上手示例集：一叠可直接跑起来、可部署的小项目，覆盖对话、工具调用、Agent 等常见形态。
- **技术亮点**：每个示例独立成项目、带说明文档，是官方推荐的「从零到能部署」路径；2024 年 8 月建仓，累计 19,425 星、3,280 fork，与 anthropics/skills 一起构成 Anthropic 的开源新手生态。
- **适用场景**：第一次接 Claude API 的开发者、想看官方最佳实践写法的工程师、内部培训教材。
- **许可证**：MIT。
