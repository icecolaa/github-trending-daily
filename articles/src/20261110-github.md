## 项目简介

### 01 · sherlock-project/sherlock｜+4,267
经典 OSINT 工具：输入一个用户名，跨 400+ 社交平台排查该账号是否存在，结果可导出 JSON / CSV 接进调查流水线。Python 实现，站点清单与请求模板插件化；2018 年建仓，今天总 star 到 107,080，是本期最老也涨得最猛的仓库。适合用户名溯源、账号关联分析、红队侦察的信息收集阶段。MIT 许可。

### 02 · meta/astryx｜+3,278
Meta 开源的下一代设计系统：150+ 无障碍组件，既给人用，也给「与人并肩工作的 Agent」用。README 自述这套系统在 Meta 内部长了八年、支撑 13,000+ 应用；开源版基于 React 19+ 与 StyleX，主打品牌级 token 定制，目前 Beta。今日单日 +3,278，总 star 首次破 2 万。适合想要「Meta 级」组件基建的前端团队。MIT 许可。

### 03 · milind-soni/OpenMausBot｜+1,587
开源的 Grok Bot 替代品：把一队 AI Agent 装进聊天软件，每个侧边栏「联系人」都是一个真实运行的 bot，各有模型、人设和一台云端虚拟机，关键操作可人工审批。TypeScript + React 19 + Electron，本地优先、自带模型。2026 年 8 月建仓，三个月到 19,692 星。适合想要本地多 Agent 工作台的重度用户。Apache-2.0 许可。

### 04 · anthropics/skills｜+1,038
Anthropic 官方的 Agent Skills 仓库：一组「文件夹形式的技能包」，每个自带 `SKILL.md` 与脚本，Claude 动态加载后可在专项任务上获得可复现提升。覆盖创作、Web 应用测试、MCP 服务器生成、企业流程等方向，是学写 skill 的官方范本库。191,000 星，为本期总 star 最高。仓库无统一根许可证，多数 skill 标注 Apache-2.0，整体待核实。

### 05 · vercel-labs/agent-browser｜+916
给 AI Agent 用的浏览器自动化 CLI：一条命令让 Agent 打开页面、点击、填表、抓数据，避免自己写一套 Playwright 胶水。Rust 实现，2026 年 1 月建仓，总 star 48,485。这是它近 7 天第三次出现在本榜（11-06 +150、11-09 +815、今日 +916），增量还在放大。适合做 Agent 联网操作的团队。Apache-2.0 许可。

### 06 · google-deepmind/mujoco｜+574
DeepMind 的通用多关节动力学物理仿真器，机器人仿真的事实标准之一。C++ 核心，接触动力学求解器兼顾精度与速度，原生支持 MJX（JAX 后端）做 GPU 并行；被强化学习训练、机械臂与人形机器人研究广泛依赖。2021 年 8 月开源进 DeepMind，16,916 星。适合 sim-to-real 流程与物理引擎教学。Apache-2.0 许可。

### 07 · anthropics/claude-quickstarts｜+551
Anthropic 官方的 Claude API 快速上手示例集：一叠可直接运行、可部署的小项目，覆盖对话、工具调用、Agent 等常见形态，每个示例独立成项目并带说明。2024 年 8 月建仓，20,023 星，与 anthropics/skills 组成 Anthropic 的开源新手生态。MIT 许可。

### 08 · ZhuLinsen/daily_stock_analysis｜+506
LLM 驱动的多市场股票分析系统：A 股、港股、美股、日股、韩股、台股自选股，每日自动生成「决策仪表盘」并推送到企业微信、飞书、Telegram、Discord、Slack 或邮箱。多源行情 + 实时新闻，可跑在 GitHub Actions / Docker 上零成本定时。2026 年 1 月建仓，68,869 星，是本期总 star 第二高的项目。MIT 许可。

### 09 · garrytan/gbrain｜+216
给已有 Agent 加一层「自己掌控的记忆」：显式事实连同出处一起存，支持更正与撤回，跨 Agent 复用；起步只用关键词检索，需要时再加语义搜索、综合回答与知识图谱。作者是 YC 总裁 Garry Tan，用于自己的 OpenClaw / Hermes 部署（15 万页、2.4 万人、5,340 家公司），可通过 MCP 暴露给 Claude、ChatGPT、Cursor。2026 年 4 月建仓，32,162 星。MIT 许可。

### 10 · ruvnet/RuView｜+172
用普通 WiFi 信号做空间感知：靠 ESP32 采集信道状态信息（CSI），穿墙检测有人/人数、测呼吸与心率、识别走动与跌倒，不需要摄像头和穿戴设备。原生对接 Home Assistant、Apple Home、Google Home、Alexa 与 Matter，每节点出 21 个实体。2025 年 6 月建仓，103,472 星。适合智能家居与无摄像头看护场景。MIT 许可。
